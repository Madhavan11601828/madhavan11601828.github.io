## 🛠️ Local Development

### Prerequisites
- Ruby 2.7 or higher
- Jekyll

### Setup
```bash
bundle install
bundle exec jekyll serve
```

Visit `http://localhost:4000` to view your blog locally.

## 📂 Structure

```
├── _config.yaml       # Jekyll configuration
├── index.md          # Homepage
├── README.md         # This file
└── _posts/           # Blog posts (YYYY-MM-DD-title.md)
```

## ✍️ Adding New Posts

1. Create a new file in `_posts/` with format: `YYYY-MM-DD-title.md`
2. Add frontmatter:
```yaml
---
title: "Your Post Title"
author: "Mangena Venu Madhavan"
date: 2026-01-25
tags: [tag1, tag2, tag3]
---
```
3. Write your content in Markdown
4. Commit and push to trigger GitHub Pages build
